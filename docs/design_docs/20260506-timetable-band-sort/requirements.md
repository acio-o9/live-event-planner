# Requirements: Timetable Band Sort

**Status**: Draft
**Created**: 2026-05-06
**Developer**: maru

## What（何を作るか）

タイムテーブルのバンド順を出演順にソートする機能を実装する。
バンド一覧画面でバンドを長押しまたはドラッグ操作することで出演順を入れ替えられるようにし、
変更した順序がタイムテーブルにも反映されるようにする。

## Why（なぜ必要か）

出演順が変更になった場合、タイムテーブルのバンドが追加順（createdAt順）のまま表示されるため見づらくなる。
出演順を明示的に管理・反映できるようにし、タイムテーブルの可読性を向上させる。

## Requirements（要件）

### Functional Requirements（機能要件）

- [ ] バンド一覧で、バンドを長押しまたはドラッグ操作することで出演順を入れ替えできる
- [ ] タイムテーブルのバンドの並びは出演順（order フィールド値）になっている
- [ ] 並び替え操作はadmin・honki_kanrininのみ実行できる（一般ユーザーはドラッグUI非表示）
- [ ] 並び替え結果はサーバーに永続化され、リロード後も保持される

### Non-Functional Requirements（非機能要件）

- [ ] ドラッグ操作のUIレスポンス: 100ms以内（楽観的UI更新）
- [ ] モバイル対応: タッチ長押しドラッグによる並び替えが動作する
- [ ] デスクトップ・モバイル両方でレイアウト崩れなし

## Success Criteria（成功基準）

- [ ] バンド一覧でドラッグ&ドロップによる並び替えが正常に動作する
- [ ] タイムテーブルがソート後の出演順で正しく表示される
- [ ] admin・honki_kanrinin以外のユーザーはソートUIが表示されない
- [ ] ソート結果がページリロード後も保持される
- [ ] すべてのテストが通過する
