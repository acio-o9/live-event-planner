# Requirements: Live Notice Tab

**Status**: Draft
**Created**: 2026-05-07
**Developer**: maru

## What（何を作るか）

ライブ詳細ページに「連絡事項」タブを追加する。
マークダウン（markdown-it）で入稿された内容を表示する画面を提供する。
タブはナビゲーションの一番左に配置し、admin・本気管理人が編集できる。
表示エリアをクリックすると編集モードに切り替わり、保存ボタンでマークダウン表示に戻る。

## Why（なぜ必要か）

確定した情報や注意事項をストック情報として残したい。
現在は連絡事項を記録・共有する場所がなく、情報が散逸する。

## Requirements（要件）

### Functional Requirements（機能要件）

- [ ] 連絡事項タブをナビゲーションの一番左に追加する
- [ ] markdown-it ライブラリでマークダウンをHTMLにレンダリングして表示する
- [ ] admin・本気管理人のみ編集可能（他ロールは読み取り専用）
- [ ] 権限ありユーザーが表示エリアをクリックすると編集モード（テキストエリア）に切り替わる
- [ ] 保存ボタンを押すとAPIに保存し、マークダウン表示モードに戻る
- [ ] 未入力（null）の場合は空状態メッセージを表示する

### Non-Functional Requirements（非機能要件）

- [ ] マークダウンレンダリング: 200ms以内
- [ ] XSS対策: markdown-it のサニタイズ設定 (html: false) を使用
- [ ] レスポンシブ対応（最小1200px）

## Success Criteria（成功基準）

- [ ] 連絡事項タブがナビゲーションの一番左に表示される
- [ ] マークダウン記法（見出し・リスト・太字など）が正しくレンダリングされる
- [ ] admin・本気管理人のみが編集モードに入れる（userロールではクリックしても編集モードにならない）
- [ ] 保存後にマークダウン表示モードに切り替わり、内容が反映される
- [ ] すべてのテストが通過する
